# On-performance-and-energy-efficiency-of-AI-algorithms

## Datasets:

Find three processed datasets used for writing thesis in Datasets/For report:

### Results_main_CIFAR100.csv contains main results:

- Run configuration 10 epochs on CIFAR100. Most configurations ran 15-20 times, the average is taken of each configuration.

### Results results_different_datasets.csv contains:

- Running configurations 10 epochs on other datasets like CIFAR10, Stanford Dogs and FashionMNIST

### Results results_main_epoch1_epoch10.csv contains:

- Running configurations for 10 epochs in CIFAR100 with per epoch-monitoring. These are the datapoints used in plots in Results
